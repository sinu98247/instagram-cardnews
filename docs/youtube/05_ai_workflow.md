# 05. AI 보조 제작 워크플로

## 1. 원칙
- **AI는 속도, 사람은 판단.** 리서치 요약, 대본 초안, 자막, 컷 편집, 썸네일 시안은 AI에게 맡기고, 주제 선택, 관점, 실험 실행, 사실 검증, 최종 목소리는 사람이 합니다.
- **YouTube 정책 리스크**: 템플릿으로 찍어낸 듯한 반복 영상, 남의 콘텐츠를 짜깁기한 영상, 사람의 기여 없이 AI 음성과 스톡 영상만 쓴 영상은 YPP 심사에서 "부적절한(반복적·대량생산) 콘텐츠"로 거절될 위험이 큽니다. 매 영상에 **직접 한 실험, 화면 녹화, 본인의 해석**이 들어가야 합니다.
- **모든 숫자는 출처 2곳**: 기존 파이프라인의 교차확인 규칙을 영상에도 똑같이 적용합니다.

## 2. 주간 제작 파이프라인 (롱폼 2 + Shorts 7 기준, 주 12~15시간)

| 단계 | 소요 | 담당 | 산출물 |
|---|---|---|---|
| 1. 리서치·기획 | 1.5h (주 1회) | AI 70% / 사람 30% | 주간 기획안 2편 + Shorts 7개 주제 |
| 2. 패키징 | 0.5h/편 | 사람 + AI 시안 | 제목 5안 → 1안, 썸네일 콘셉트 3안 |
| 3. 대본 | 1.5h/편 | AI 초안 → 사람 재작성 | 최종 대본 + 화면 지시 |
| 4. 실험·화면 녹화 | 1~2h/편 | 사람 | 원본 녹화 |
| 5. 녹음 | 0.5h/편 | 사람 (본인 목소리) | 음성 파일 |
| 6. 편집 | 2h/편 | AI 자동 컷·자막 → 사람 다듬기 | 최종 영상 |
| 7. 썸네일 | 0.5h/편 | 템플릿 + 사람 | 3안 |
| 8. 업로드·최적화 | 0.3h/편 | 체크리스트 | 예약 공개 |
| 9. Shorts 파생 | 1.5h (주 1회 일괄) | AI 클립 추출 → 사람 검수 | Shorts 7개 |
| 10. 분석·회고 | 0.5h (주 1회) | 07 문서 템플릿 | 다음 주 개선안 |

## 3. 단계별 SOP와 도구

### 3-1. 주제 리서치
**도구**: 기존 `src/collect.py` 수집 결과, Google Trends(지역: 대한민국), 네이버 데이터랩, YouTube 검색 자동완성, vidIQ 또는 TubeBuddy(키워드·경쟁도), Perplexity(출처 포함 리서치), Claude·ChatGPT(요약·각도 발굴)

**SOP**
1. 지난 7일 인스타 게시물 중 반응 상위 3개를 확인합니다(`src/insights.py` 주간 결과).
2. 02 문서의 아이디어 은행에서 시즌·이슈에 맞는 것을 2개 고릅니다.
3. 아래 프롬프트로 각도를 확장합니다.

```text
[리서치 프롬프트]
너는 한국 2030 직장인 대상 재테크×AI 유튜브 채널의 리서처야.
주제: {주제}
1) 이 주제로 시청자가 실제로 검색할 만한 한국어 검색어 10개
2) 시청자가 가장 궁금해할 질문 5개 (불안·욕구 기준)
3) 기존 영상들이 놓치는 각도 3개
4) "AI로 직접 실험"할 수 있는 실험 설계 2개 (조건, 측정 방법, 기간)
5) 확인해야 할 사실·숫자 목록과 공신력 있는 1차 출처 후보 (기관명)
모르는 숫자는 지어내지 말고 '확인 필요'로 표시해.
```

### 3-2. 대본
**도구**: Claude 또는 ChatGPT(초안), 03 문서 구조 템플릿

```text
[대본 초안 프롬프트]
아래 정보로 {길이}분 유튜브 대본 초안을 써줘.
- 구조: {03 문서의 구조 A/B/C 표 붙여넣기}
- 제목/썸네일: {확정안}  ← 첫 30초에 이 약속을 바로 확인시켜야 함
- 내 실험 결과/데이터: {직접 얻은 결과}
- 톤: 친한 회사 선배 존댓말, 과장 금지, 문장은 짧게(한 문장 40자 이내)
- [화면: ...] 형태로 화면 지시를 같이 써줘
- 40%와 70% 지점에 재훅 문장, 중간에 오픈 루프 1개
- 특정 종목 매수/매도 권유 금지, 확인 안 된 숫자는 {확인필요}로 표시
```

**사람이 꼭 할 일**: {확인필요} 표시된 곳을 1차 출처로 채우기, 내 경험 문장 3개 이상 추가, 소리 내어 읽으면서 어색한 문장 수정, 첫 30초는 직접 다시 쓰기.

### 3-3. 음성
| 옵션 | 도구 | 권장도 |
|---|---|---|
| **본인 목소리** (권장) | USB 마이크(다이내믹 마이크 권장) + Audacity 또는 Adobe Podcast Enhance(잡음 제거) | ★★★ 신뢰, 정책, 차별화 |
| AI 보이스 클론 (본인 목소리 학습) | ElevenLabs, Typecast 등 | ★★ 수정 녹음이나 Shorts 보조용 |
| 일반 AI 성우 | Typecast, Clova Dubbing 등 | ★ 비권장 (신뢰와 정책 리스크) |

녹음 팁: 대본을 단락별로 녹음하고, 틀리면 그 문장만 다시 녹음합니다. 파일명은 `편번호_단락번호`. 서서 녹음하면 톤이 살아납니다.

### 3-4. 촬영·화면 녹화
- **도구**: OBS Studio(무료, 화면 녹화), 폰 카메라(손·책상 B-roll), Screen Studio 또는 Cursorful류(자동 줌 화면 녹화, 선택)
- 해상도는 1920×1080 이상, 브라우저 확대 125~150%로 글자 가독성을 확보합니다.
- 개인정보(계좌번호, 카드번호, 이메일, API 키)는 녹화 전에 가리거나 편집에서 블러 처리합니다. **특히 이 저장소의 Secrets와 토큰이 화면에 나오지 않게 주의하세요.**

### 3-5. 편집
- **도구**: Vrew(한국어 자동 자막·텍스트 기반 컷 편집, 초벌용으로 매우 빠름), CapCut(효과·Shorts), DaVinci Resolve(무료 고급 편집), Premiere Pro(선택)
- **편집 순서**: Vrew로 무음·실수 자동 컷 → 자막 검수 → 화면 녹화 싱크 → 줌·강조(5~10초마다 시각 변화) → 그래픽(숫자 카드) → BGM(-28~-32dB, 저작권 해결된 YouTube 오디오 보관함) → 효과음 최소화 → 내보내기
- **그래픽 재사용**: 기존 `templates/card.html`과 `style.css`의 팔레트와 폰트로 "숫자 카드" 템플릿을 만들어 두면, 영상 속 그래픽과 인스타 카드가 같은 브랜드로 보입니다.

### 3-6. 썸네일
- **도구**: Figma 또는 Canva(레이아웃 템플릿 3종 저장), Photoshop(선택), AI 이미지 생성(배경 소스용. 실존 인물이나 브랜드 로고를 오해 소지 있게 합성하지 않음)
- **SOP**: 템플릿 복제 → 문구 4단어 → 메인 비주얼 1개 → 3안 변형(문구, 색, 표정·오브젝트 중 하나만 변경) → 폰에서 실제 크기 확인 → 테스트 및 비교 등록

### 3-7. 게시
- 03·04 문서의 업로드 체크리스트를 따릅니다.
- 예약 공개, 자막 SRT 업로드, 엔드스크린, 재생목록, 고정 댓글까지 확인합니다.
- 공개 직후 인스타 스토리와 카드 마지막 장에 링크를 걸고, 커뮤니티 탭에 공지합니다.

### 3-8. 분석
- 07 문서 템플릿으로 매주 일요일 30분. 인스타 주간 성과(`insights.yml`)와 같은 날 같이 봅니다.

## 4. 재가공 (1 롱폼 → 10개 이상 콘텐츠)

| 산출물 | 플랫폼 | 방법 | 도구 |
|---|---|---|---|
| Shorts 3~4개 | YouTube Shorts | 결과 장면, 반전, 팁 하나, 프롬프트 하나를 각각 30~50초 세로 클립으로 | Opus Clip 등 자동 클립 → CapCut 수정 |

| 블로그 글 1개 | 네이버 블로그·티스토리 | 대본 → 글 변환, 검색 유입과 쿠팡파트너스 연결 | Claude |

> 플랫폼마다 같은 영상을 그대로 올려도 되지만, **첫 1초 텍스트와 캡션은 플랫폼별로 바꾸면** 성과가 좋아집니다. 다른 플랫폼 워터마크가 남은 영상은 업로드하지 않습니다.

### 이 저장소를 활용한 Shorts 반자동화 (선택 과제)
현재 파이프라인(수집 → 원고 → 카드 렌더)에 다음 단계를 추가하면 "오늘의 경제 숫자" Shorts 초안을 매일 자동으로 만들 수 있습니다.
1. `render.py`에서 1080×1920 세로 카드 변형 출력
2. 카드 6장을 ffmpeg로 이어 붙여 장당 3~5초 슬라이드 영상 생성 (줌·전환 효과)
3. 원고 문장을 자막 SRT로 출력
4. 텔레그램으로 초안 전송 → **사람이 목소리 녹음과 검수를 한 뒤 업로드**

YouTube 자동 업로드까지 붙이는 것은 정책 리스크 때문에 권장하지 않습니다. 원하시면 이 단계를 구현해 드릴 수 있습니다.

## 6. 품질 관리(QC) 체크리스트

### 대본 QC
- [ ] 첫 30초 안에 제목과 썸네일의 약속을 확인시켜주는가
- [ ] 모든 숫자에 출처 2곳이 있는가 (확인필요 표시 0개)
- [ ] 내 경험이나 실험 문장이 3개 이상 있는가
- [ ] 오픈 루프 1개 이상, 재훅 2개 이상
- [ ] 종목 권유, 수익 보장, 공포 조장 표현이 없는가
- [ ] 소리 내어 읽었을 때 어색한 문장이 없는가

### 편집 QC
- [ ] 첫 5초에 인트로, 로고, 인사가 없는가
- [ ] 15초 이상 같은 화면이 없는가
- [ ] 자막 오탈자 0개 (특히 숫자와 고유명사)
- [ ] 음량: 대사 -14 LUFS 근처, BGM이 대사를 가리지 않음
- [ ] 개인정보, 계좌, API 키 노출이 없는가
- [ ] 저작권: BGM, 이미지, 타 채널 클립의 사용 권한이 확인되었는가

### 패키징 QC
- [ ] 폰 크기에서 썸네일 문구가 읽히는가
- [ ] 썸네일과 제목이 같은 말을 반복하지 않는가
- [ ] 썸네일 3안을 준비했는가
- [ ] 제목 앞 25자에 핵심이 있는가

### 업로드 QC
- [ ] 설명란, 챕터, 출처, 고지문
- [ ] 자막 SRT, 엔드스크린, 재생목록, 고정 댓글
- [ ] 유료 광고 및 AI 합성 표시 여부 확인
- [ ] 공개 시간이 예약되었는가
