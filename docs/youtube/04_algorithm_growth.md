# 04. 알고리즘 이해 · 성장 전략

## 1. 추천 시스템을 한 문장으로
> YouTube는 영상을 밀어주지 않습니다. **"이 시청자가 이 영상을 보고 만족할 확률"**을 예측해서 시청자에게 영상을 찾아줍니다.

그래서 내가 통제할 수 있는 건 결국 두 가지입니다.
1. **누구에게** 보여줘야 할지 신호를 명확히 준다: 일관된 주제, 메타데이터, 시청자층
2. 보여줬을 때 **만족 신호**를 많이 받는다: 클릭, 시청, 좋아요, 공유, 재방문, 설문 만족

## 2. 성장 깔때기와 핵심 지표

```
노출(Impressions) ─→ 클릭(CTR) ─→ 시청(AVD·리텐션) ─→ 만족(참여·설문) ─→ 재방문·구독
   "보여줄까?"        "누를까?"       "계속 볼까?"         "좋았나?"         "또 올까?"
```

| 단계 | 지표 | 의미 | 초기 채널 목표치 (가이드) |
|---|---|---|---|
| 노출 | 노출수 | 썸네일이 화면에 표시된 횟수 | 영상당 첫 7일 2,000~10,000 |
| 클릭 | 노출 클릭률(CTR) | 노출 대비 클릭 | 4~10% (신규 채널은 노출이 적어 높게 나오기도 함) |
| 시청 | 평균 시청 지속시간(AVD) | 평균 몇 분 봤나 | 롱폼 길이의 35~50% |
| 시청 | 30초 시점 유지율 | 훅이 먹혔나 | 70% 이상 |
| 만족 | 좋아요·댓글·공유율 | 조회수 대비 | 좋아요 3~5%, 댓글 0.5% 이상 |
| 재방문 | 재방문 시청자 비율 | 다시 온 사람 | 20~30% 이상 |
| 전환 | 구독 전환율 | 조회수 대비 신규 구독 | 1~3% (실험·튜토리얼이 높음) |

> **CTR과 AVD는 같이 봅니다.** CTR이 높은데 AVD가 낮으면 낚시로 판단되어 노출이 줄어듭니다. CTR이 낮은데 AVD가 높으면 패키징만 고치면 되는 숨은 보석입니다.

## 3. 트래픽 소스별 공략

| 소스 | 작동 방식 | 내 채널 전략 |
|---|---|---|
| **YouTube 검색** | 검색어와 영상의 관련성, 그리고 그 검색어에서의 만족도 | 초기 1~2개월의 엔진. 튜토리얼(③)과 시즌 절세 콘텐츠. 제목 앞부분에 검색어, 설명란 첫 2줄에 키워드 자연스럽게, 챕터 활용 |
| **탐색 기능(홈)** | 시청 이력 기반 개인화. 초기에는 내 구독자와 비슷한 사람에게 테스트 노출 | 실험(①)이 담당. 강한 패키징이 핵심. 처음 24~72시간 반응이 테스트 결과를 좌우 |
| **추천 동영상** | 지금 보는 영상 옆과 끝에 노출 | 큰 채널이 다루는 주제(금리, AI 신모델)를 내 각도로 다룸. 내 영상끼리 연결(엔드스크린, 재생목록, 시리즈) |
| **Shorts 피드** | 스와이프 피드에서 완주율·반복재생·스와이프 이탈률로 판단 | 하루 1개. 구독 유입과 채널 노출용. 롱폼 연결은 "관련 동영상" 링크 기능 활용 |
| **외부** | 인스타, 블로그, 커뮤니티 | @s_98247 카드 마지막 장과 스토리에서 유입. 초기 시딩용이며 외부 유입만으로 키우려 하지 않음 |
| **재생목록·채널 페이지** | 연속 시청 | 기둥별 재생목록, 채널 홈의 "추천 영상"에 최고 전환 영상 배치 |

### 초기 채널의 현실
- 업로드 직후에는 기존 구독자와 비슷한 시청자에게 작게 테스트 노출됩니다. 구독자가 0이면 이 테스트 풀이 작기 때문에 **검색과 Shorts로 시청자 데이터를 먼저 쌓아야** 탐색 노출이 열립니다.
- 영상은 몇 주, 몇 달 뒤에 갑자기 노출되는 경우가 흔합니다. **처음 48시간 성적만으로 영상을 버리지 마세요.**
- 주제가 흩어지면 시청자 프로필이 흐려집니다. 첫 30편은 4개 기둥 안에서만 만듭니다.

## 4. 업로드 빈도 전략

| 단계 | 기간 | 롱폼 | Shorts | 근거 |
|---|---|---|---|---|
| 런치 | 1~4주 | 주 2편 | 주 5편 | 데이터 확보, 패키징 테스트 |
| 성장 | 5~12주 | 주 2편 (그중 실험 1편 필수) | 주 7편 | 승리 포맷에 집중 |
| 가속 | 13주~ | 주 2~3편 | 주 7~10편 | 파이프라인이 안정되면 확장 |

- **빈도보다 일관성이 중요합니다.** 매주 같은 요일과 시간에 올립니다. 추천: 롱폼은 화·금 19:00(KST) 공개, Shorts는 매일 07:30 또는 12:00.
- 실제 최적 시간은 YouTube Studio의 "시청자가 YouTube를 이용하는 시간"을 30일 데이터로 확인한 뒤 조정합니다.
- 공개 1~2시간 전에 예약 업로드를 걸어서 처리와 HD 인코딩을 끝내 둡니다.
- 품질이 떨어질 것 같으면 롱폼 1편 + Shorts로 줄입니다. 저품질 영상은 채널 평균 신호를 깎습니다.

## 5. 테스트 방법론

### A. 패키징 테스트
- **썸네일 A/B**: Studio "테스트 및 비교"에 매번 3안을 넣습니다. 결과는 시청시간 점유율 기준으로 나옵니다(최대 2주).
- **제목 교체**: 7일 후 CTR이 채널 중앙값보다 30% 이상 낮으면 제목을 교체합니다. 바꾼 날짜를 트래커에 기록합니다.
- **사전 테스트**: 업로드 전에 제목 후보 5개를 인스타 스토리 투표나 지인 3명에게 보여주고 고릅니다.

### B. 포맷 테스트 (2주 단위 가설)
```
가설: "AI 대결형"이 "단일 AI 튜토리얼"보다 탐색 노출이 높을 것이다
방법: 같은 주제 범위에서 대결형 2편, 튜토리얼 2편
측정: 7일 노출수, CTR, AVD%, 구독 전환율
결론: 승자 포맷 비중을 늘리고 패자는 개선안 1회 더 테스트 후 판단
```

### C. 훅 테스트
- 같은 롱폼에서 Shorts 2개를 서로 다른 훅으로 만들어 완주율을 비교합니다. 이긴 훅 스타일을 롱폼 오프닝에 적용합니다.

### D. 기록 원칙
- 한 번에 변수 하나만 바꿉니다.
- 모든 테스트는 [content_tracker.csv](content_tracker.csv)의 `test_note` 열에 기록합니다.

## 6. 최적화 전술 체크리스트 (업로드마다)
- [ ] 제목: 검색 키워드 + 호기심, 40자 이내 권장
- [ ] 설명란 1~2줄: 영상 요약 + 핵심 키워드 + 리드 마그넷 링크
- [ ] 챕터(00:00부터 시작, 3개 이상)
- [ ] 태그는 보조 수단입니다. 오타·변형어 3~5개만
- [ ] 자막: 직접 검수한 한국어 SRT 업로드 (자동 자막보다 정확해 검색과 접근성에 유리)
- [ ] 엔드스크린: 특정 영상 1개 + 구독 버튼
- [ ] 재생목록에 추가 (기둥별)
- [ ] 고정 댓글: 링크 + 질문
- [ ] Shorts는 관련 롱폼을 "관련 동영상"으로 연결
- [ ] 투자·금융 콘텐츠는 "투자 권유 아님" 고지, 광고 포함 시 "유료 광고 포함" 체크
- [ ] 실사처럼 보이는 AI 합성 장면이 있으면 "변경되거나 합성된 콘텐츠" 표시
- [ ] 공개 후 1시간 안에 댓글에 답글 달기 (초기 참여 신호이자 커뮤니티 형성)

## 7. 시청자 → 구독자 전환 시스템

| 장치 | 방법 |
|---|---|
| **시리즈 설계** | "AI 포트폴리오 월간 결과"처럼 다음 편이 예정된 콘텐츠. 구독할 명확한 이유가 생김 |
| **약속 반복** | 매 영상에서 "매주 AI 돈 실험 1개" 채널 약속을 1문장으로 반복 |
| **가치 후 요청** | 핵심 인사이트를 준 직후에만 구독 요청 |
| **채널 홈 최적화** | 비구독자용 채널 트레일러(60초 안에 채널 약속과 대표 실험 하이라이트), 섹션은 기둥별 |
| **구독 전환 영상 찾기** | Studio에서 "구독자 증가에 기여한 동영상" 상위 3개를 엔드스크린과 Shorts 연결 대상으로 지정 |
| **커뮤니티 탭** | 구독자 500명 전후로 사용 가능해지면 투표("다음 실험 뭐 할까요?")로 재방문 유도 |
| **리드 마그넷** | 템플릿과 프롬프트 팩 → 뉴스레터 → 새 영상 알림 (플랫폼 밖 재방문 채널) |

## 8. 정체기 진단 순서
1. **노출이 줄었나?** → 주제가 시청자 관심에서 벗어났거나 패키징 피로. 최근 승리 주제의 변형을 만들고 썸네일 스타일을 새로 고칩니다.
2. **노출은 그대로인데 CTR이 하락했나?** → 썸네일과 제목 문제. 3안 테스트를 강화하고 경쟁 썸네일 옆에 놓고 비교합니다.
3. **CTR은 정상인데 AVD가 하락했나?** → 훅과 중반 문제. 리텐션 그래프에서 급락 구간을 찾아 편집 규칙을 수정합니다(07 문서).
4. **다 정상인데 구독 전환만 낮나?** → 시리즈화와 채널 약속 부재. CTA 위치와 다음 영상 연결을 점검합니다.
