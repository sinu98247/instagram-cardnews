# 08. 90일 실행 계획

- **기간**: 0주 차(준비) 2026-11-25~11-29 → **Day 1 = 2026-11-30(월) ~ Day 90 = 2027-02-27(토)**
- 이 기간은 **연말 절세(12월)와 연말정산(1~2월) 피크**를 그대로 통과합니다. 기둥 ③ 튜토리얼로 검색 유입을 잡기 가장 좋은 타이밍입니다.
- 투입 시간 가정: 평일 1.5시간, 주말 4~5시간 (주 약 15시간)

### 생산성 시스템
- **배치 작업**: 녹음, 썸네일, Shorts는 몰아서 합니다. 맥락 전환 비용을 줄이기 위해서입니다.
- **버퍼 2편**: 3주 차까지 롱폼 2편을 미리 만들어 비축합니다. 아프거나 야근해도 업로드가 끊기지 않습니다.
- **완벽주의 차단**: 영상당 편집 시간 상한 2.5시간. 넘기면 그대로 공개하고 다음 영상에서 개선합니다.
- **보드 관리**: 노션 칸반(아이디어 → 기획 → 대본 → 녹음 → 편집 → 예약 → 공개 → 리뷰)과 [content_tracker.csv](content_tracker.csv)
- **번아웃 방지**: 주 1일 완전 휴식. 4주마다 "가벼운 주"(롱폼 1편 + Shorts)를 허용합니다.

## 7. 4,000시간 경로 계산기 (매월 갱신)
```
남은 시간 = 4,000 - 최근 12개월 누적 공개 시청시간
월 필요 시청시간 = 남은 시간 ÷ 남은 개월 수
필요 월 조회수 = 월 필요 시청시간 × 60 ÷ 평균 AVD(분)

예) 90일 시점 1,800h, 6개월 안에 달성하려면
   월 필요 = 2,200 ÷ 6 ≈ 367h
   AVD 5분이면 월 롱폼 조회 약 4,400회 필요
   → 에버그린 영상 24편이 편당 월 180회만 나와도 충족 (기존 영상의 누적 효과)
```
