# 07. 데이터 분석 · 성과 최적화 시스템

## 1. 지표 계층 (무엇을 먼저 보나)

```
북극성 지표: 주간 시청시간(시간) + 주간 신규 구독자
   ├─ 도달: 노출수, 트래픽 소스 구성
   ├─ 패키징: 노출 클릭률(CTR)
   ├─ 콘텐츠: 평균 시청 지속시간(AVD), 평균 시청 비율(AVD%), 30초 유지율, 리텐션 그래프 형태
   ├─ 관계: 재방문 시청자, 좋아요·댓글·공유, 구독 전환율
   └─ 수익(승인 후): RPM, CPM, 제휴 클릭·전환, 상품 매출
```

## 2. 지표별 해석 가이드

| 지표 | 어디서 | 해석 | 행동 |
|---|---|---|---|
| **노출수** | Studio > 분석 > 도달 | 알고리즘이 테스트해주는 규모 | 성장세면 같은 주제를 확장, 감소세면 주제·패키징 리프레시 |
| **CTR** | 도달 | 노출이 커질수록 자연스럽게 하락함. **같은 노출 규모의 내 영상끼리** 비교 | 채널 중앙값 대비 -30%면 썸네일·제목 교체 |
| **AVD / AVD%** | 참여도 | 롱폼 35% 미만이면 훅이나 구성 문제 | 리텐션 그래프 진단 |
| **리텐션 그래프** | 영상별 > 참여도 | 구간별 이탈 | 아래 패턴표 참고 |
| **30초 유지율** | 리텐션 그래프 "인트로" 지표 | 훅 성능 | 70% 미만이면 다음 영상 훅 재설계 |
| **구독 전환율** | 신규 구독자 ÷ 조회수 | 채널 약속의 설득력 | 1% 미만이면 시리즈화와 CTA 점검 |
| **재방문 시청자** | 시청자층 | 팬층 형성 | 비율 하락 시 시리즈와 커뮤니티 강화 |
| **트래픽 소스** | 콘텐츠 > 트래픽 소스 | 검색 vs 탐색 vs 추천 비중 | 탐색이 늘면 추천 진입 신호 |
| **검색어** | 트래픽 소스 > YouTube 검색 | 실제 유입 키워드 | 다음 영상 제목과 주제에 반영 |
| **"시청자가 시청하는 다른 채널"** | 시청자층 | 내 시청자의 관심 지도 | 콜라보 대상, 주제 각도 발굴 |
| **RPM** | 수익 | 1,000회당 실수령 | 고단가 주제 비중 조정 |

### 리텐션 그래프 패턴 진단

| 패턴 | 모양 | 원인 | 해결 |
|---|---|---|---|
| 초반 절벽 | 0~30초에 40% 이상 이탈 | 썸네일 약속 불일치, 느린 인트로 | 결과를 첫 5초에, 인사 삭제 |
| 완만한 하강 | 계속 서서히 하락 | 정상. 기울기가 문제 | 재훅 추가, 시각 변화 늘리기 |
| 중간 급락 | 특정 구간에서 뚝 떨어짐 | 지루한 설명, 광고, 주제 이탈 | 그 구간 길이 50% 축소, 다음 영상 규칙화 |
| 상승 구간(봉우리) | 그래프가 올라감 | 다시보기, 건너뛰어 온 사람 | 그 장면이 핵심 → 썸네일과 Shorts 소재로 |
| 엔딩 절벽 | 결론 시작과 함께 이탈 | "마무리 신호" 멘트 | 결론을 짧게, 다음 영상으로 바로 연결 |

## 3. 벤치마크 설정법
- 초기에는 외부 평균보다 **내 채널 중앙값**을 기준선으로 씁니다. 최근 10편 롱폼의 CTR, AVD%, 7일 조회수 중앙값을 기준으로 삼습니다.
- 등급 분류 (7일 기준):
  - 🟢 **승리**: 조회수 중앙값의 1.5배 이상 **그리고** AVD%가 중앙값 이상
  - 🟡 **보통**: 0.7~1.5배
  - 🔴 **부진**: 0.7배 미만

## 4. 주간 리뷰 프레임워크 (매주 일요일 30분)

### 부진 영상 개선 진단 트리
```
7일 조회 부진
 ├─ 노출이 적다 (< 채널 중앙값의 50%)
 │    → 주제 수요 문제: 같은 주제 반복 금지, 검색어 재선정, 2주 뒤 재평가
 ├─ 노출은 정상, CTR이 낮다
 │    → 썸네일 교체(테스트 및 비교) → 3일 뒤 제목 교체 → 그래도 낮으면 주제 문제로 분류
 ├─ CTR 정상, AVD%가 낮다
 │    → 리텐션 그래프에서 최대 급락 구간 기록 → 편집·대본 규칙에 추가
 │    → (기존 영상은 YouTube 편집기로 지루한 구간 잘라내기 가능)
 └─ 다 정상인데 구독 전환이 낮다
      → 엔드스크린과 CTA 수정, 시리즈 연결
```

## 6. 승리 패턴 데이터베이스
트래커(CSV)에 아래 열을 꾸준히 기록하면 3개월 뒤 피벗 테이블로 패턴이 보입니다.

`id, publish_date, pillar, format, title_formula, thumb_layout, hook_type, length_min, impressions_7d, ctr_7d, views_7d, avd_pct, ret_30s, subs_gained_7d, sub_conv, top_traffic_source, grade, test_note`

### 분석 질문 10개 (월간)
1. 어떤 기둥이 구독 전환율이 가장 높은가?
2. 어떤 제목 공식이 CTR 상위 25%에 가장 많이 들어가는가?
3. AI 대결형 vs 단일 실험형, 탐색 노출 차이는?
4. 영상 길이와 AVD% 사이의 관계 (최적 구간)?
5. 숫자가 들어간 썸네일 vs 안 들어간 썸네일?
6. 시즌 주제(절세)의 검색 유입 지속 기간은?
7. Shorts → 롱폼 연결 클릭이 많은 Shorts 유형은?
8. 인스타에서 반응 좋았던 주제가 유튜브에서도 통했나?
9. 댓글이 많은 영상의 공통점은?
10. 재방문 시청자를 가장 많이 만든 시리즈는?

## 7. 수익 지표 (승인 후)

| 지표 | 공식 | 활용 |
|---|---|---|
| RPM | 총수익 ÷ 조회수 × 1,000 | 주제별 수익성 비교 |
| 시청시간당 수익 | 광고 수익 ÷ 시청시간 | 긴 영상의 실제 가치 판단 |
| 제휴 EPC | 제휴 수익 ÷ 링크 클릭 | 추천 상품 교체 판단 |
| 리드 전환율 | 이메일 가입 ÷ 조회수 | 리드 마그넷 성능 |
| 상품 전환율 | 구매 ÷ 이메일 구독자 | 상품·가격 검증 |
| 구독자 1인당 월 수익 | 월 총수익 ÷ 구독자 | 채널 비즈니스 건강도 |

## 8. 자동화 아이디어 (선택)
이 저장소의 `src/insights.py` 패턴을 확장해서 **YouTube Data API와 YouTube Analytics API**로 주간 지표를 수집하고 텔레그램으로 요약을 받는 워크플로를 만들 수 있습니다. 시청시간, 구독, 영상별 CTR, AVD%를 매주 자동 집계해 위 주간 리뷰 템플릿의 1번 섹션을 자동으로 채우는 방식입니다(OAuth 설정 필요).
