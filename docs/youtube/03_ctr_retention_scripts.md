# 03. CTR · 리텐션 제작 시스템 + 완성 대본

## 1. 패키징 우선 원칙
**영상은 제목과 썸네일을 먼저 정하고 나서 만듭니다.** 패키징이 매력적이지 않은 아이디어는 촬영하지 않습니다.

### 패키징 3초 테스트
1. 썸네일과 제목을 폰 화면 크기로 줄여서 3초만 봅니다.
2. "무슨 내용인지" 한 문장으로 말할 수 있어야 합니다. **명확성**
3. "그래서 결과가 뭔데?"라는 궁금증이 생겨야 합니다. **호기심 격차**
4. 타깃(김대리)이 "나한테 해당되는 얘기"라고 느껴야 합니다. **관련성**

## 2. 제목 공식 12가지

| # | 공식 | 예시 |
|---|---|---|
| 1 | AI한테 [돈 문제] 맡겨봤다 | AI한테 월급 관리 3개월 맡겨봤다 |
| 2 | [AI A] vs [AI B] vs [AI C], [과제] 누가 이기나 | 챗GPT vs Claude vs Gemini, 연말정산 누가 제일 정확할까 |
| 3 | [숫자] + [구체적 결과] | 소비 분석했더니 새는 돈 월 47만 원 |
| 4 | [상황]인 사람만 보세요 | 월급 300, 적금만 하는 사람만 보세요 |
| 5 | [날짜] 전에 안 하면 손해 | 12월 31일 전에 안 하면 13월의 월급 날아갑니다 |
| 6 | 이렇게 쓰면 망하고, 이렇게 쓰면 돈 된다 | 챗GPT 주식 분석, 이렇게 쓰면 망합니다 |
| 7 | [시간]만에 [결과] (템플릿 제공) | 10분 만에 가계부 자동화 (템플릿 무료) |
| 8 | [뉴스], 내 [통장·대출]엔 정확히 얼마? | 금리 0.25% 인하, 내 대출 이자는 정확히 얼마? |
| 9 | [기간] 도전 결과 | 퇴근 후 30분 AI 부업 30일, 진짜 번 돈 |
| 10 | 다들 틀리는 [주제] | ISA, AI도 사람도 다 틀리는 부분 |
| 11 | 결국 [결과]였습니다 | AI 추천 종목 1년 검증, 결국 이렇게 됐습니다 |
| 12 | [금지·경고]형 | 연금저축 이렇게 넣으면 세금 더 냅니다 |

**제목 규칙**
- 앞 25자 안에 핵심 키워드와 결과 궁금증을 넣습니다. 모바일에서는 그 뒤가 잘립니다.
- 썸네일 문구와 제목은 **보완 관계**여야 합니다. 같은 말을 반복하지 않습니다.
- 낚시 금지: 제목이 약속한 것을 **영상 처음 60초 안에 확인**시켜줘야 이탈이 생기지 않습니다.
- 숫자는 구체적으로 씁니다. "많이"보다 "47만 원"이 강합니다.

## 3. 썸네일 시스템

### 기본 레이아웃 3종 (템플릿화해서 반복 사용)
| 레이아웃 | 구성 | 언제 |
|---|---|---|
| **A. 대결형** | AI 로고 3개를 나란히 + 승자에 왕관이나 패자에 X + 큰 숫자 | AI 비교 실험 |
| **B. 결과형** | 큰 숫자(+32% / -47만 원) + 화살표 그래프 + 놀란 얼굴(선택) | 실험 결과, 계산 |
| **C. 문제해결형** | 지저분한 Before → 깔끔한 After 시트·대시보드, 2분할 | 튜토리얼 |

### 규칙
- 텍스트는 **최대 4단어(한글 10자 내외)**, Pretendard ExtraBold, 외곽선이나 그림자를 넣습니다.
- 경제 콘텐츠는 네이비 배경 + 골드 포인트, AI 콘텐츠는 다크 배경 + 퍼플·시안 포인트로 채널 일관성을 유지합니다.
- 피사체는 하나만 크게 둡니다. 모바일 크기(약 168×94)에서도 읽혀야 합니다.
- 오른쪽 아래(재생시간 표시 위치)에는 중요한 요소를 두지 않습니다.
- 매 영상 **썸네일 3개 버전**을 만들어 YouTube Studio의 "테스트 및 비교"로 A/B 테스트합니다.

### 썸네일 콘셉트 예시 (Tier S 아이디어용)
| # | 썸네일 문구 | 비주얼 |
|---|---|---|
| 1 | "AI 셋, 1천만 원" | AI 로고 3개 + 각자 수익률 숫자를 가린 상태(?) + 돈다발 |
| 2 | "알아서 올라감" | 폰 화면에 인스타 피드가 자동으로 쌓이는 모습 + 시계 08:30 |
| 3 | "10분 컷" | 엉망인 영수증 더미 → 깔끔한 시트, 2분할 |
| 4 | "1년 뒤 얼마?" | 월급봉투 + 우상향 그래프 + 물음표 숫자 |
| 6 | "믿었으면…" | AI 추천 종목 차트(급락 또는 급등)에 빨간 원 |
| 9 | "누가 틀렸나" | AI 로고 3개 중 하나에 빨간 X |

## 4. 훅(첫 30초) 시스템

### 오프닝 4단 공식: **결과 예고 → 판돈 → 신뢰 → 로드맵** (총 15~30초)
1. **결과 예고 / 충격 (0~5초)**: 썸네일이 약속한 장면을 바로 보여줍니다. 인사나 채널 소개는 넣지 않습니다.
2. **판돈 (5~12초)**: 이게 시청자의 돈과 시간에 왜 중요한지 말합니다.
3. **신뢰 (12~20초)**: 내가 직접 해봤다는 근거를 보여줍니다(화면 증거).
4. **로드맵과 오픈 루프 (20~30초)**: "마지막에 ○○도 공개합니다"로 끝까지 볼 이유를 심습니다.

### 오프닝 장면 연출 가이드 (얼굴 없이 가능)
- **화면 증거 클로즈업**: 결과 숫자, 시트, 앱 화면을 확대하고 마우스 커서로 강조
- **패턴 인터럽트**: 첫 프레임에 큰 숫자 텍스트와 효과음(과하지 않게)
- **반전 B-roll**: "모두가 이렇게 생각하죠"(일반 화면) → "그런데"(실제 데이터)
- 금지: 로고 인트로 5초, "안녕하세요 ○○입니다~", 지난 영상 요약

### 구조 B: 해설형 (기둥 ②), 6~9분
훅(내 돈 영향) → 30초 요약 → 원인(왜 일어났나) → 메커니즘(그래서 어떻게 번지나) → **내 돈 계산기**(케이스 3개: 대출자, 예금자, 투자자) → 지금 할 일 → 다음 이벤트 날짜

### 구조 C: 튜토리얼형 (기둥 ③), 8~15분
완성본 먼저 보여주기 → 왜 필요한가(고통 공감) → 준비물 → 단계 1~N(각 단계 끝에 "여기서 많이 막히는 부분") → 응용 팁 → 실수 TOP3 → 템플릿 받는 법

## 6. 리텐션 기법 체크리스트
- [ ] **오픈 루프**: 30초 안에 1개, 중간(40%, 70% 지점)에 1개씩 추가로 심기
- [ ] **재훅(re-hook)**: 2~3분마다 "그런데", "여기서부터가 진짜입니다" 같은 전환 문장
- [ ] **시각 변화**: 5~10초마다 화면 변화(줌, 컷, 그래픽, B-roll). 같은 화면 정지는 15초 이하
- [ ] **챕터**: 설명란에 타임스탬프 5개 이상. 단 첫 챕터 제목은 결과를 드러내지 않게
- [ ] **숫자 시각화**: 모든 숫자는 화면에 텍스트나 그래프로 표시
- [ ] **군더더기 삭제**: "음, 어, 그러니까"와 반복 설명은 컷. 문장 사이 침묵은 0.2초 이하
- [ ] **예측 참여**: "댓글로 예측 먼저 남겨주세요" (참여 신호)
- [ ] **중간 CTA 금지 구간**: 첫 2분 안에는 구독 요청을 하지 않습니다
- [ ] **엔딩 조기 이탈 방지**: "오늘 영상은 여기까지" 같은 마무리 멘트 대신 바로 다음 영상으로 연결
- [ ] **패턴 일관성**: 시리즈는 같은 구조로 시청자 기대를 학습시킴

## 7. CTA 시스템

| 위치 | CTA | 문장 예 |
|---|---|---|
| 40~60% 지점 | 가치 기반 구독 | "이런 실험 매주 하나씩 합니다. 다음 결과 놓치기 싫으시면 구독만 해두세요." |
| 템플릿 언급 시 | 리드 마그넷 | "오늘 쓴 시트는 설명란 첫 줄 링크에서 무료로 받으실 수 있습니다." |
| 결론 직후 | 댓글 질문 | "여러분 상황(연봉, 목표)을 댓글로 주시면 다음 영상에서 AI로 계산해 드립니다." |
| 마지막 15초 | 다음 영상 | "이 실험의 1개월 결과는 이 영상에서 확인하세요." (엔드스크린 지목) |

- 구독 요청은 **영상당 1회, 가치를 준 직후**에만 합니다.
- 고정 댓글: 템플릿 링크 + 참여 질문 1개
- 엔드스크린: "시청자 맞춤 영상" 대신 **특정 후속 영상**과 재생목록을 지정합니다.

## 8. 완성 대본 ①: 아이디어 #1 (실험형, 약 11분)

**제목**: 챗GPT·Claude·Gemini한테 1,000만 원 포트폴리오 짜게 했더니 (모의투자 1편)
**썸네일**: "AI 셋, 1천만 원" + AI 로고 3개 + 물음표 수익률
**설명란 첫 줄**: 📊 AI 3개 포트폴리오 추적 시트(무료) → [링크] / ※ 모의투자이며 투자 권유가 아닙니다.

```

[0:12 판돈 - 화면: 6개월 캘린더]
```
