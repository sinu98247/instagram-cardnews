# 🫏 임금님 귀는 당나귀 귀

대나무숲에 대고 누구든 실컷 욕하고 뒷담화하면, **내 목소리로 메아리**가 돌아오는 비밀 공간.
서버 없는 단일 HTML 파일(`index.html`)입니다.

## 기능
| 기능 | 설명 |
|---|---|
| 🎙 내 목소리 등록 | 예시 문장을 읽어 녹음 → 이 기기 브라우저(localStorage)에 저장, 음높이(F0) 분석 |
| ⌨ 글로 외치기 | 쓴 글이 구멍에서 떠오르고, 대나무숲이 3번(점점 작게) 메아리 |
| 📣 육성 외치기 | 누르고 외친 뒤 다시 누르면 **내 육성 그대로** 딜레이·잔향을 입혀 메아리 (크롬은 자막도 표시) |
| 🍃 날려보내기 | 화면에 떠 있는 말을 바람에 날려 지움 |
| 숲 반응 | 소리 크기에 따라 대나무가 흔들림 |
| 🎧 스피커 사고 방지 | 소리 내기 전 이어폰 확인. 소리 장치가 바뀌거나(이어폰 빠짐) 다른 앱으로 가면 즉시 정지 후 재확인 |
| 🙈 숨기기 | 한 번 탭(PC는 Esc)으로 평범한 "업무 메모" 화면으로 위장. 제목을 길게 누르면 복귀. ⚙에서 "돌아오면 위장 화면부터" 설정 가능 |
| ⚡ 빠른 문장 | 자주 쓰는 욕 저장(＋ 저장)/삭제(✎ 편집). `{이름}` 자리는 ⚙의 "욕할 대상 이름"으로 자동 채움 |
| 메아리 끄기 | ⚙에서 끄면 이어폰으로 한 번만 또렷하게 |

### 글 → 목소리 엔진 (화면 왼쪽 위에 표시)
- ⚪ **기본 음성**: 목소리 미등록 시 기기 내장 한국어 TTS
- 🟡 **내 톤 흉내**: 등록한 목소리의 음높이에 맞춰 내장 TTS 높낮이 조절 (완전히 같은 목소리는 아님)
- 🟢 **진짜 내 목소리**: ⚙에 ElevenLabs API 키를 넣으면 샘플로 목소리를 복제해 글을 내 목소리로 합성 + 숲 메아리 효과.
  이 모드에선 샘플과 글이 ElevenLabs로 전송됩니다. 실패하면 자동으로 🟡 모드로 대체.

## 실행
마이크는 HTTPS 또는 localhost에서만 동작합니다.
```bash
cd donkey-ears
python3 -m http.server 8000
# http://localhost:8000
```
휴대폰에서 쓰려면 GitHub Pages나 Netlify 등 HTTPS 정적 호스팅에 `index.html`만 올리면 됩니다.

## 개인정보
- 입력한 글과 육성 외침은 서버로 가지 않고 메모리에만 있다가 창을 닫으면 사라집니다.
- 목소리 샘플·음높이·API 키만 이 기기 브라우저에 저장되며, 🎙 → "목소리 삭제", ⚙ → "키 지우기"로 지울 수 있습니다.
