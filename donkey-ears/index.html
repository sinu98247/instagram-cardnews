임금님 귀는 당나귀 귀

임금님의 비밀을 알게 된 복두장이는 끝내 참지 못하고 대나무숲에 들어가 외쳤어요. "임금님 귀는 당나귀 귀!"

여기는 그 대나무숲이에요. 상사, 친구, 전 애인, 세상 누구든 실컷 욕하고 뒷담화해도 괜찮아요. 숲은 당신 목소리로 메아리만 돌려줄 뿐이에요.

회의 중에도, 자리에서도 🎧 이어폰 끼고 타이핑만 하면 내 목소리로 상사 욕을 들을 수 있어요. 누가 오면 🙈 숨기기.

🔒 여기서 한 말은 서버에 저장되지 않고, 창을 닫으면 사라져요.

🎙 내 목소리 등록

아래 문장을 평소 목소리로 읽어주세요. 10초 이상이면 좋아요. 중간에 틀리면 ✕ 취소 후 다시 녹음하면 돼요.

옛날 옛적, 임금님의 귀가 당나귀 귀라는 걸 아는 사람이 있었어요. 너무 말하고 싶어서 참다 참다 대나무숲에 들어가 있는 힘껏 외쳤답니다. 임금님 귀는 당나귀 귀! 속이 다 시원하네!

🟢 진짜 내 목소리로 말하기

기본 모드는 휴대폰/PC에 내장된 한국어 음성을 내 음높이에 맞춰 바꾸는 방식이라 "비슷한 톤"까지만 돼요.

ElevenLabs API 키를 넣으면 등록한 샘플로 목소리를 복제해서, 쓴 글을 진짜 내 목소리로 읽어줘요.

💳 목소리 복제는 ElevenLabs 유료 플랜(Starter 이상)에서 돼요. 샘플은 30초~1분 정도로 녹음할수록 더 닮아요.

⚠ 이 모드에선 목소리 샘플과 입력한 글이 ElevenLabs로 전송돼요. 키는 이 기기 브라우저에만 저장돼요.

✍ 글을 내 목소리로 들으려면

휴대폰 혼자서는 녹음한 목소리로 새 문장을 만들어 낼 수 없어요. 목소리를 학습해서 말해주는 목소리 복제 AI(ElevenLabs)를 연결해야 해요.

지금 바로 내 목소리를 듣고 싶다면 📣 버튼을 누르고 직접 외치면 돼요. 녹음한 육성 그대로 메아리쳐요.
