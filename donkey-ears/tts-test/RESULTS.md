# 자체 목소리 복제 테스트 1차 (2026-11-11)

ElevenLabs 없이 공개 모델로 "타이핑 → 내 목소리"가 되는지 확인한 테스트.

- 모델: MeloTTS-Korean(글 → 기본 AI 음성) + OpenVoice V2(음색을 대상 목소리로 변환). 둘 다 MIT.
- 대상 목소리: Zeroth-Korean(CC BY 4.0) 실제 화자 4명(남 1, 여 3), 화자당 36~78초 참조 음성.
- 장비: CPU 4코어, GPU 없음.

## 결과

| 화자 | 같은 사람 실제 녹음 | 복제 결과 | 변환 전 AI 음성 | 다른 사람 | 음높이(원본→복제) |
|---|---|---|---|---|---|
| 남성 A (187) | 0.97 | 0.89 | 0.48 | 0.57 | 128 → 123Hz |
| 여성 A (105) | 0.96 | 0.86 | 0.75 | 0.65 | 247 → 221Hz |
| 여성 B (126) | 0.97 | 0.92 | 0.86 | 0.79 | 233 → 215Hz |
| 여성 C (132) | 0.98 | 0.88 | 0.85 | 0.77 | 200 → 191Hz |

닮은 정도는 화자 인식 모델(microsoft/wavlm-base-plus-sv)의 코사인 유사도. 1에 가까울수록 같은 사람.

- 속도(CPU): 문장당 글→음성 4~6초 + 음색 변환 약 1.2초. 목소리 등록(음색 추출)은 1초 미만.
- 발음(Whisper-small 받아쓰기): 4문장 중 2문장은 완벽. "귀"가 "비/뒤"로, "퇴근"이 "팩은"으로 받아쓰인 경우가 있음(받아쓰기 모델 오류일 수도 있음).
- 욕설 문장("아 씨, 진짜 개빡치네")은 그대로 정확히 읽음.

## 판단
- 복제 결과는 대상 목소리 쪽으로 분명히 이동하지만(0.86~0.92), 실제 같은 사람(0.96~0.98)에는 못 미침.
- 억양과 말투는 기본 AI 음성 그대로임(음색만 바뀜).
- CPU로는 문장당 5~7초라 채팅용으로는 느림. GPU 필요.
- 사람이 직접 들어보는 평가가 아직 필요함.

## 재현
`synth.py`(합성), `evalsv.py`(측정). 모델은 Hugging Face `myshell-ai/OpenVoiceV2`, `myshell-ai/MeloTTS-Korean`,
코드는 GitHub `myshell-ai/OpenVoice`, `myshell-ai/MeloTTS`.

## 직접 들어본 평가와 프로젝트 상태 (2026-11-11)
- 직접 들어본 결과: **감정이 실리지 않음.** 욕을 해도 또박또박 읽는 말투라 속풀이 느낌이 나지 않음.
- 결정: **프로젝트 당분간 중단.**
- 재개 조건: 감정(화, 짜증)을 실어 말하는 목소리 복제가 가능해질 때.
- 재개 시 먼저 볼 것: 억양·감정까지 따라 하는 방식의 모델(CosyVoice 2, GPT-SoVITS, IndexTTS-2 등)과
  ElevenLabs의 감정 표현 기능. 같은 문장·같은 화자로 `synth.py`/`evalsv.py`와 비교.
