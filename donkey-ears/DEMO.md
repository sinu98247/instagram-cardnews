## 시연 전 체크리스트 (5분)
- [ ] **브라우저**: 안드로이드는 크롬, 아이폰은 사파리 (카톡·인스타 안의 브라우저는 마이크가 막힐 수 있음 → "다른 브라우저로 열기")
- [ ] **무음 모드 해제** + 미디어 볼륨 최대 (아이폰은 옆 무음 스위치 꼭 확인)
- [ ] 링크 열고 **🎙 내 목소리 등록을 미리 해두기** (한 번 하면 그 기기에 저장됨)
- [ ] 마이크 권한 "허용" 눌러두기
- [ ] 발표장이 크면 블루투스 스피커 연결 (메아리 효과가 훨씬 살아요)
- [ ] 화면 공유가 필요하면 PC 크롬에서 열어도 똑같이 동작

## 3분 시연 대본

**① 오프닝 (30초) — 인트로 화면**
> "다들 임금님 귀는 당나귀 귀 이야기 아시죠? 비밀을 못 참은 사람이 대나무숲에 가서 외쳤던 그 이야기요.
> 이 앱이 바로 그 대나무숲입니다. 여기선 누구를 욕해도, 뒷담화를 해도 괜찮아요. 아무도 안 듣거든요."

→ **[숲으로 들어가기]** 탭. 밤의 대나무숲이 열림.

**② 글로 외치기 (40초)**
> "먼저 글로 외쳐볼게요."

→ 아래 빠른 버튼 **[김부장님 퇴근 좀 시켜주세요!]** 탭
→ 구멍에서 글자가 떠오르고, 내 톤의 목소리로 3번 점점 작게 메아리 + 대나무가 흔들림

> "제가 미리 목소리를 등록해놔서, 제 목소리 톤으로 숲이 따라 말해줘요." (왼쪽 위 🟡 표시 가리키기)

**③ 육성으로 외치기 — 하이라이트 (60초)**
> "이번엔 진짜로 외쳐보겠습니다."

→ **📣** 탭 → 크게 **"임금님 귀는 당나귀 귀!!!"** → **■** 탭
→ 내 육성이 대나무숲 울림으로 왼쪽·오른쪽에서 메아리 (크롬이면 자막도 뜸)

> "소리가 클수록 대나무가 더 크게 흔들려요. 속이 시원해지죠?"

**④ 날려보내기 + 마무리 (30초)**
→ **🍃 날려보내기** 탭 → 글자들이 바람에 날아감

> "다 외쳤으면 바람에 날려보내면 끝. 여기서 한 말은 서버에 저장되지 않고, 창을 닫으면 사라집니다.
> 다음 단계는 목소리 복제로 글도 100% 내 목소리로 읽어주고, 여러 명이 익명으로 함께 쓰는 숲으로 확장하는 거예요."

**(선택) 관객 참여** — QR 보여주고 "직접 외쳐보세요!"

## 예상 질문
| 질문 | 답변 |
|---|---|
| 글도 진짜 내 목소리로 나와요? | 지금은 기기 내장 음성을 내 음높이에 맞춘 "비슷한 톤"이에요. ⚙에 목소리 복제 서비스(ElevenLabs) 키를 넣으면 진짜 내 목소리로 나오는 기능이 들어가 있어요. |
| 욕한 내용 저장돼요? | 아니요. 서버가 없고, 창을 닫으면 사라져요. 목소리 샘플만 그 기기에 남고 🎙에서 삭제할 수 있어요. |
| 다른 사람도 들을 수 있어요? | 지금은 혼자만의 숲이에요. 여러 명이 함께 쓰는 버전은 실명 욕설이 명예훼손이 될 수 있어서 이름 자동 가리기 같은 장치와 함께 준비 중이에요. |

## 문제 생기면
| 증상 | 해결 |
|---|---|
| 소리가 안 나요 | 무음 스위치/볼륨 확인 → 화면 한 번 탭 → 새로고침 |
| 마이크 버튼 눌러도 안 돼요 | 주소창 🔒 → 마이크 허용. 카톡·인스타 앱 안이면 크롬/사파리로 다시 열기 |
| 녹음 후 소리가 작아요 (아이폰) | 녹음이 끝나면 자동으로 마이크를 끄도록 해뒀어요. 그래도 작으면 볼륨 버튼을 한 번 눌러주세요 |
| 링크가 안 열려요 | 노트북에서 `cd donkey-ears && python3 -m http.server 8000` → `http://localhost:8000` (PC 시연용) |
| 목소리 다시 하고 싶어요 | 🎙 내 목소리 → ● 다시 녹음 |
