# 한걸음 공부방 — 초등 1·2학년 국어·수학·영어·과학

`index.html` 하나로 동작하는 태블릿 학습 앱 + `print/`의 인쇄용 PDF 학습지.
현재 초등학교 전 학년에 적용되는 **2022 개정 교육과정**을 기준으로 했습니다. 부모님 공간 → 설정에서 1학년/2학년을 바꿀 수 있고, 기본은 2학년입니다.

## 하루 루틴 (2학년 약 20분)
국어 5문제 → 몸 깨우기 15초 → 수학 → 몸 깨우기 → 영어 → 몸 깨우기 → 과학 → 스티커

## 2학년 단계 (총 34단계)
| 과목 | 단계 (교육과정 영역) |
|---|---|
| 국어 | 소리와 다르게 쓰는 낱말(문법) → 헷갈리는 낱말(쓰기) → 문장 부호(문법) → 흉내 내는 말(문학) → 반대말과 비슷한 말(문법) → 꾸며 주는 말(쓰기) → 높임 표현(듣기·말하기) → 글 읽고 답하기(읽기) |
| 수학 | 세 자리 수 → 받아올림 덧셈 → 받아내림 뺄셈 → □가 있는 식·세 수 계산 → 곱셈의 뜻 → 곱셈구구 (수와 연산) → 길이 재기 cm·m → 시각과 시간 (도형과 측정) → 규칙 찾기와 표 (변화와 관계·자료와 가능성) → 여러 가지 도형 (도형과 측정) |
| 영어 | 알파벳 순서 → 단모음 파닉스 → 듣고 단어 읽기 → 생활 낱말 → 인사와 기본 표현 → 문장 듣고 그림 찾기 → 숫자 11~20 (3학년 영어 준비) |
| 과학 | 나: 몸과 건강 → 자연: 계절의 변화 → 동물의 한살이 → 동물 분류 → 식물의 생활 → 물체와 물질 → 자석 → 빛과 소리 → 마을과 세계 (통합교과 + 3학년 과학 준비) |

영어와 과학은 3학년부터 정규 과목이라, 2학년 과정은 통합교과(나·자연·마을·세계) 내용과 3학년 수업 준비로 구성했습니다. 수학 2학년은 숫자 패드로 답을 직접 입력합니다.

## 1학년 단계 (총 28단계)
국어 한글 해득(첫소리·자음·모음·글자 만들기·낱말·문장), 수학 10까지 수·덧셈·뺄셈·50까지의 수·시계, 영어 알파벳·파닉스·기초 어휘, 과학 통합교과 관찰·분류.

## 설계 원리
- 떠올리기 연습 (Roediger & Karpicke 2006), 간격 복습 1일 → 3일 (Cepeda et al. 2006)
- 완전 학습: 80% 이상 두 번이면 다음 단계 (Bloom 1984)
- 틀리면 한 번 더 기회, 기록은 첫 시도 기준
- 과목 사이 움직임 휴식 (Chang et al. 2012), 문제 소리로 읽어주기
