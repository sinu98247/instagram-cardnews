# 한걸음 공부방 — 초등 1~6학년 국어·수학·영어·과학

태블릿 학습 앱(`index.html` + `js/`)과 인쇄용 PDF 학습지(`print/`). 현재 초등학교 전 학년에 적용되는 **2022 개정 교육과정** 기준입니다.

## 배우는 방식 (모든 학년·모든 단계)
1. **그림 영상 (배우기)**: 내레이션과 움직이는 그림으로 개념을 설명합니다. 이어서 예제 2개를 "생각할 시간 → 정답"으로 함께 풉니다. 처음 보는 단계에서는 자동으로 먼저 나옵니다.
   - 장면 종류: 수직선 뛰어 세기, 10씩 묶기, 자릿값 표, 묶어 세기(곱셈), 똑같이 나누기(나눗셈), 분수 원·막대, 시계 돌리기, 각도 벌리기, 넓이 칸 채우기, 한살이·순환 흐름, 자음+모음 합치기, 파닉스 소리 잇기
2. **3D 입체**: Three.js로 직접 돌려 봅니다.
   - 여러 가지 모양(1학년), 쌓기나무(2·6학년), 지구와 달(3·6학년), 지층과 화석(4학년), 물질의 상태 알갱이(4·6학년), 태양계(5학년), 전개도 접기(5·6학년), 각기둥·각뿔·원기둥·원뿔·구(6학년)
3. **문제 풀기**: 단계별 완전 학습(80% 이상 2번이면 다음 단계), 틀린 문제는 1일·3일 뒤 복습. 고학년 수학은 숫자 패드(소수점 포함)로 직접 입력합니다.
4. **영상 더 보기**: 학습을 마치면 단원 이름으로 YouTube 검색 링크를 줍니다(부모님과 함께 보기 권장).

3~6학년은 교육과정 학년군(3~4, 5~6) 성취기준을 바탕으로 학년별 단계를 나눴습니다. 실제 단원 배치는 교과서마다 다를 수 있어 부모님 공간에서 단계를 조정할 수 있습니다. 영어는 1~2학년이 3학년 준비 과정, 과학은 1~2학년이 통합교과 기반입니다.

## 파일
- `index.html`: 앱 본체, 1~2학년 과정
- `js/g3.js`~`js/g6.js`: 3~6학년 과정
- `js/visuals.js`: 분수·각도·그래프·도형 그림
- `js/lessons.js`: 그림 영상 플레이어와 단원별 설명
- `js/three-scenes.js`: 3D 장면 (Three.js r128을 cdnjs에서 필요할 때 불러옴)
- `print/N학년_과목_학습지.pdf`: 24개 + `주간_공부_기록표.pdf`

기록은 기기 브라우저(localStorage)에만 저장됩니다.
