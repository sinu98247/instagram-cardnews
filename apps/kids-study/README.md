# 한걸음 공부방 — 초등 1학년 국어·수학·영어·과학

`index.html` 하나로 동작하는 태블릿 학습 앱 + `print/`의 인쇄용 PDF 학습지.
"몰입 랩"(apps/mollip-lab)에서 정리한 집중·학습 연구를 7세 아이에 맞게 적용했습니다.

## 하루 루틴 (약 15분)
국어 5문제 → 몸 깨우기 15초 → 수학 → 몸 깨우기 → 영어 → 몸 깨우기 → 과학 → 스티커

## 단계 (총 28단계)
| 과목 | 단계 |
|---|---|
| 국어 | 첫소리 찾기 → 자음 이름 → 모음 알기 → 글자 만들기 → 낱말 읽기(받침 없음) → 낱말 읽기(받침 있음) → 문장 완성 |
| 수학 | 10까지 세기 → 수의 순서와 크기 → 10까지 덧셈 → 10까지 뺄셈 → 50까지의 수 → 시계 보기 → 20까지와 두 자리 셈 |
| 영어 | 알파벳 듣기 → 대문자와 소문자 → 첫소리 파닉스 → 단어 듣고 그림 찾기 → 색깔 → 숫자 |
| 과학 | 동물이 사는 곳 → 살아 있는 것 → 계절 → 우리 몸과 감각 → 뜰까 가라앉을까 → 자석 → 날씨와 생활 → 식물의 한살이 |

국어·수학은 2022 개정 교육과정 1학년 내용, 영어는 알파벳·파닉스 기초(정규 영어는 3학년부터), 과학은 1학년 통합교과(슬기로운 생활)의 관찰·분류 활동을 바탕으로 했습니다.

## 설계 원리
- **떠올리기 연습**: 모든 활동이 고르거나 떠올리는 문제 (Roediger & Karpicke 2006)
- **간격 복습**: 틀린 문제는 1일 → 3일 뒤 다시 출제, 두 번 맞히면 졸업 (Cepeda et al. 2006)
- **완전 학습**: 한 단계에서 80% 이상을 두 번 맞혀야 다음 단계 (Bloom 1984)
- **한 번 더 기회**: 틀리면 바로 답을 주지 않고 한 번 더 생각하게 함. 기록은 첫 시도 기준
- **움직임 휴식**: 과목 사이 15초 신체 활동 (Chang et al. 2012)
- **소리로 읽어주기**: 기기 음성(한국어·영어)으로 문제를 읽어 줌

## 부모님 공간
덧셈 문제로 잠금. 7일 현황(과목별 단계·정답률), 복습 상자, 단계 직접 조정, 학습지 생성(매번 새 문제 + 정답 쪽), 설정(이름, 문제 수, 음성, 휴식).
