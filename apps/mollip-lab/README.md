# 몰입 랩 — 집중력 × AI 활용 트레이닝 앱

단일 HTML 앱(`index.html`). 서버나 빌드 없이 동작하며, 기록은 브라우저 localStorage에만 저장됩니다.

## 연구 → 기능 매핑

### 집중력
| 연구 결과 | 근거 수준 | 앱 기능 |
|---|---|---|
| 작업 전환 비용 (Monsell 2003) | 강함 | 한 세션 = 한 가지 일, 탭 정리 체크 |
| 주의 잔여물 (Leroy 2009) | 중간 | 떠오른 할 일 "보관" |
| 방해받으면 스트레스 증가 (Mark et al. 2008) | 중간 | 알림 끄기, 화면 없는 휴식 |
| 만약–그러면 계획, d≈0.65 (Gollwitzer & Sheeran 2006) | 강함 | 세션 설계 단계 |
| 깨어 있는 시간의 47%는 딴생각 (Killingsworth & Gilbert 2010) | 중간 | "딴생각 알아챔" 버튼 |
| 2주 마음챙김 훈련 효과 (Mrazek et al. 2013) | 중간 | 호흡 훈련 |
| 호흡 세기 과제 (Levinson et al. 2014) | 중간 | 호흡 세기 모드 + 정확도 |
| 사이클릭 한숨 5분 (Balban et al. 2023) | 중간 | 사이클릭 한숨 모드 |
| 휴대폰이 곁에 있기만 해도 영향 (Ward et al. 2017, 재현 결과 혼재) | 예비 | 폰 다른 방 두기 |
| 수면 부족과 주의력 (Lim & Dinges 2010) | 강함 | 기본기 체크 |
| 운동 직후 실행기능 향상 (Chang et al. 2012) | 강함 | 기본기 체크 |

### AI 활용 능력
| 연구 결과 | 근거 수준 | 앱 기능 |
|---|---|---|
| 생성 효과·인출 연습 (Slamecka & Graf 1978; Roediger & Karpicke 2006) | 강함 | "먼저 생각하기": 내 초안 먼저 |
| GPT를 그냥 쓰면 시험 성적 17% 하락, 튜터형은 방지 (Bastani et al. 2025, PNAS) | 중간 | "비판부터 받기" 옵션 |
| 들쭉날쭉한 경계 (Dell'Acqua et al. 2023) | 중간 | 검증 체크리스트 |
| AI를 신뢰할수록 비판적 사고 감소 (Lee et al. 2025, CHI) | 중간 | 3단계 검증 |
| LLM 사용 시 뇌 연결성 저하 (Kosmyna et al. 2025, 프리프린트) | 예비 | 생각 먼저, AI는 나중 |
| 인지적 떠넘기기 상관 (Gerlich 2025) | 예비 | 설명 가능성 체크 |
| 명확한 지시·맥락·예시 (Brown et al. 2020; 제공사 가이드) | 강함 | 프롬프트 6요소 + 드릴 |

## 화면
- **오늘**: 집중 분·세션·딴생각·AI 훈련 통계, 7일 차트, 기본기 체크 6개
- **집중**: 설계(할 일·완료 기준·만약–그러면·환경 점검) → 타이머(딴생각 탭, 생각 보관) → 돌아보기
- **호흡**: 호흡 세기(1–9) / 사이클릭 한숨, 3·5·10분
- **AI**: 먼저 생각하기(초안 → 프롬프트 설계 → 검증), 모호한 프롬프트 고치기 드릴 8문제
- **근거**: 위 연구 요약과 근거 수준
